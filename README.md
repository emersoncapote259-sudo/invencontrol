# Sistema web de gestión de inventarios

Este proyecto consiste en el desarrollo de un sistema web para el manejo de inventarios en pequeños supermercados y negocios comerciales.

La idea principal del sistema es ayudar a mejorar el control de los productos, evitar errores que normalmente ocurren cuando todo se maneja de forma manual y facilitar la organización de la información del inventario.

## Funciones principales

El sistema permite realizar funciones como:

- Inicio de sesión para usuarios.
- Registro de productos.
- Consulta y búsqueda de productos.
- Control de entradas y salidas de inventario.
- Alertas de productos con poco stock o próximos a vencer.
- Visualización de reportes y estadísticas.

## Tecnologías utilizadas

Para el desarrollo del proyecto se utilizaron herramientas y tecnologías web como:

- HTML
- CSS
- JavaScript
- React
- Next.js
- Tailwind CSS
- Figma para el diseño del prototipo

## Objetivo del proyecto

Desarrollar una herramienta que permita mejorar la gestión de inventarios en pequeños negocios, facilitando el registro y control de los productos de una manera más organizada y eficiente.

## Resultado esperado

Con este sistema se busca:

- Mejorar el control del inventario.
- Reducir errores manuales.
- Tener la información más organizada.
- Facilitar el manejo de los productos.
- Ayudar en la toma de decisiones.
